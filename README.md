# 🔫 TrueFloat

> A platform for analyzing Counter-Strike 2 inventories and skin values.

**TrueFloat** is a full-stack project developed for study and portfolio purposes. The main goal is to build a tool that evaluates CS2 inventories by cross-referencing skin data (such as Float Value and wear condition) with real market prices.

## 🚀 Technologies Used

The project adopts a **Monorepo** structure, separating the data server (Backend) and the visual interface (Frontend).

**Backend (Rest API):**
*   **Java**
*   **Spring Boot** (Web, DevTools)
*   **Maven** (Dependency management)
*   **Lombok** (Code optimization)

**Frontend (Work in progress):**
*   Next.js / React
*   Tailwind CSS
